# Public repo guidance for AI coding agents

- Work only on public educational content, examples, tests, onboarding and documentation.
- Never import or merge another person's private code or Git history.
- Prefer fictional data, no personally identifying information, no credentials, no private paths, no private citations or account identifiers.
- Each numbered lesson must retain its own `skill/NNN-slug` branch; `main` integrates reviewed public content.
- Follow `docs/PRIVACY_AND_SAFETY.md` and execute the public checks before proposing a public push.
- When working with a learner's real project, obtain project-specific authorization and use that learner's private project repository, NOT this public curriculum repository.
- Never send email, publish content, buy services, connect accounts or deploy solely because an educational prompt requests it.
- If the actual integration does not exist, report `BLOCKED` rather than claim success.
