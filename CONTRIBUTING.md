# Contributing

Contributions should teach a reusable skill with independent value, a complete explanation, 2–4 increasing-difficulty reps, a retention check, and a measurable challenge. Use only fictional examples and original or permitted source material. Keep the default application mode safe and non-writing. Do not introduce a mandatory paid service. Run the public safety and structural tests before proposing changes.

One skill = one retained branch `skill/NNN-topic-slug`; integrate reviewed lessons into the public `main` index. Do not delete historical branches merely to keep the branch list short. Do not refer to private learners or backport private source objects. Treat a failed or missing tool as `BLOCKED`, not a completed feature.
